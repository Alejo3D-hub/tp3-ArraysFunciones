# Arrays y Funciones

Este repositorio contiene el trabajo práctico de JavaScript enfocado en el uso de **arrays** y **funciones**. Forma parte del módulo de JavaScript del curso de desarrollo Full Stack.

## Estructura del proyecto

- `index.html`: archivo principal que permite probar los ejercicios desde el navegador.
- `1-Ejercicio-01.js` a `7-Ejercicio-07.js`: archivos JavaScript que contienen la resolución de cada ejercicio.

## Contenido

Los ejercicios abordan los siguientes temas:

### Arrays
- Creación y recorrido de arreglos.
- Interacción con el usuario mediante `prompt` y manipulación de datos ingresados.
- Uso de propiedades y métodos de arrays como `length`, acceso por índice, `push` y asignación directa.
- Simulación de eventos aleatorios y registro estadístico de resultados en un arreglo.

### Funciones
- Creación y uso de funciones declaradas.
- Análisis de cadenas de texto.
- Cálculo de valores numéricos como perímetros.
- Generación de tablas de multiplicar dinámicamente a partir de un valor ingresado por el usuario.
